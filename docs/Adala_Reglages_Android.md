# Réglages Android à faire sur l'appareil de la commerciale

À faire une fois, avant de lui remettre l'appareil. Les noms des menus peuvent légèrement changer selon la marque (Samsung, Xiaomi…).

| # | Où | Réglage |
|---|----|---------|
| 1 | Paramètres → **Localisation** | **Activée**. **Précision de la localisation Google** (ou « Améliorer la précision ») : **activée**. |
| 2 | Paramètres → Applications → **Chrome** → Autorisations → **Position** | **Autoriser seulement si l'appli est en cours d'utilisation** + **Utiliser la position exacte**. |
| 3 | Paramètres → Applications → **Chrome** → Autorisations → **Appareil photo** | **Autoriser seulement si l'appli est en cours d'utilisation**. |
| 4 | Paramètres → Applications → **Chrome** → Autorisations → **Notifications** | **Autoriser** (prévu pour les rappels de relance plus tard ; facultatif aujourd'hui). |
| 5 | Chrome → ⋮ → Paramètres → Paramètres des sites → **visites.adalacola.com** | Position : **Autoriser** · Appareil photo : **Autoriser**. |
| 6 | Paramètres → Applications → **Chrome** → **Batterie** | **Non restreinte** (ou « Ne pas optimiser ») : l'envoi des visites en attente reprend plus vite au retour du réseau. |
| 7 | Paramètres → **Date et heure** | **Date et heure automatiques** et **Fuseau horaire automatique** : **activés**. Sinon, chaque visite déclenche une alerte « heure décalée ». |
| 8 | Paramètres → Applications → **Chrome** → **Données mobiles** | **Données en arrière-plan** autorisées. |
| 9 | Chrome → visites.adalacola.com → ⋮ → **Installer l'application** | L'icône **Adala Visites** est sur l'écran d'accueil. |

**Contrôle final** : ouvre l'app, appuie sur **Nouvelle visite**. Le bandeau vert « Position trouvée (précision ±… m) » doit s'afficher, et le bouton photo doit ouvrir la caméra arrière.

**À ne pas activer** : aucune autorisation de position « Toujours » / « en arrière-plan ». L'app n'en a pas besoin, et ce serait contraire au RGPD.
